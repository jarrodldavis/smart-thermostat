Smart Thermostat

Install, connect to Wi-Fi, and bring your thermostat into Home Assistant.

For the ESP32-S3 V0.7.3 prototype with 16 MB flash only. Disconnect the board from the UWP and HVAC wiring before USB installation. For an initial installation, select “Erase device” in the installer’s advanced options; this removes existing settings. HVAC outputs remain disabled until you confirm equipment setup.

  1. Record your existing thermostat settings. Connect the disconnected board by USB using a data cable.
  2. Install the firmware below and enter your Wi-Fi credentials when prompted.
  3. In Home Assistant, open Settings → Devices & services and add the discovered ESPHome device.
  4. In ESPHome Device Builder, adopt the device to create your editable configuration and configure API encryption.
  5. Follow the commissioning guide before reconnecting HVAC equipment. Confirm the provisional GPIO41/Y2 mapping.

This browser does not support Web Serial. Use a desktop browser with Web Serial support, or install through ESPHome Device Builder using USB.

Open this installer over HTTPS to use USB installation.

If serial Wi-Fi provisioning is unavailable, open Diagnostics → Wi-Fi setup on the thermostat. The protected fallback network starts automatically when Wi-Fi is unavailable. Join the displayed network using its on-screen password, then open 192.168.4.1.
